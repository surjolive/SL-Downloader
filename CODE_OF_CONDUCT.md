# Code of Conduct

## Our standard

SL Downloader aims to be a welcoming, practical, and respectful project. Participants are expected to:

- Be respectful and constructive.
- Assume good intent while discussing technical decisions.
- Focus feedback on the work, not the person.
- Welcome different backgrounds and experience levels.
- Protect user privacy and project security.

Unacceptable behavior includes harassment, discrimination, personal attacks, doxxing, sexualized conduct, threats, and publishing private information without consent.

## Enforcement

Project maintainers may edit or remove comments, close discussions, or restrict participation when this standard is violated. Serious or repeated violations may result in removal from the project.

Report conduct concerns privately through the maintainer's GitHub profile: https://github.com/surjolive

This code of conduct is adapted from the Contributor Covenant community standard.
